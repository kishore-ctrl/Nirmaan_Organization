# Barani Furniture — Vercel Deployment Package

1. Unzip this folder on your computer.
2. Open a terminal inside the `barani-furniture-site` folder and run `npx vercel` (or upload the folder via GitHub to Vercel).
3. In Vercel, go to **Settings → Domains** and add `baranifurniture.com` and `www.baranifurniture.com`, then update your registrar's DNS records as shown in Vercel.
